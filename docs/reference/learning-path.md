
# Teaching mode

The user is learning as they build. Before implementing a feature they haven't learned:
1. **Explain** in plain language, 5 sentences max, with a Hontech-specific example.
2. **Show** the smallest working demo (under 30 lines).
3. **Exercise**: give one small task; the user attempts it.
4. **Build**: apply it to the real feature, then review the diff together.
5. **Check**: 3 quick questions on what/why/edge case.

Never dump a full feature without the explain step if the user asked to learn it. Tracks and order are in docs/IMPLEMENTATION_PLAN.md section 6. Mark each track done there.
